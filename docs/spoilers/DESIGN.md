# 真相設計（ネタバレ）

亡き恋人は久世紗夜（当時20）。水原澪は別姓で育った双子の妹。母が澪を連れて離婚し、紗夜は父と兄の家に残った。直人と紗夜の交際は島での半年。紗夜は家の監視を恐れ澪の存在を伏せ、逃げる当夜に紹介する予定だった。
七年前：紗夜が島を出る計画を灯里へ相談。直人を好きだった灯里が怜司へ出発時刻を漏らす。怜司は紗夜を旧書庫に閉じ込める。火災は傷んだ配線による事故（放火ではない）。澪が到着し扉を開けようとして負傷。直人は紗夜のコートを借りた澪を煙の中で救う。紗夜は書庫内で死亡。怜司と冬木は閉じ込めを伏せる。冬木は澪の搬送記録の時刻を変え「事故前に帰った」とする家族説明を容認。戸籍交換・死亡偽装はない。直人は入院中で救出相手を知らず、怜司から自分が救った人は使用人と告げられた。
現在：冬木が引退にあたり原記録を返す。怜司は澪の所在を探し、管理人として招く。館売却の前に追悼会で過去を認めるつもりだが、灯里の裏切りも許しなく公開しようとする。招待状本文「私を弔いに来て」は紗夜の未投函の手紙を怜司が切り貼りした複製。澪に成り代わりを要求、拒まれる。
灯里は怜司と礼拝堂で口論し、燭台で一度殴る。彼の呼吸を確かめず、灯里の手紙を持ち去る。扉の引き戸式内閂に弔花の細い黒リボンを回し、閉扉後に隙間から引いて施錠、片端を引き抜く。閂の金具に黒繊維。実験で可能性は示せるが犯人断定は別の証拠による。窓は開かず、隠し通路なし。
20:40 灯里が厨房を出る。20:43 澪が怜司と口論後出る（白い封筒を返される）。20:47 灯里が怜司と会う。20:50 怜司が鐘を7回（集会を始める合図）。20:52頃 殴打。20:55 灯里厨房へ。21:00 集合予定。21:04 全員で発見、冬木が救命を試みる。時計や鐘から死亡時刻を確定しない。
手掛かり：灯里自身が撮影した20:38弔花の長い黒リボン（自身の端末で公開）。発見時片側短い。本人のポケットに持ち出した半分の手紙。遺体の下の破片と物理的接合、血の付いた破片は本文のみ。灯里が発見前の対話で「指輪は右手」と漏らす（全員が遠くから見たのは左側、本人は見えたと言い張る→単独証拠扱いしない）。20:47目撃は澪、疑いを避け嘘をつく。自白と複数物証で結ぶ。残された指輪は怜司が七年前の遺品から持ってきた、焼失との説明は直人への嘘。
最終分岐：手紙を隠して過去へ踏み込ませない→BAD。原本を隠した主人公に対し、灯里は自分から申告、澪と冬木も証言する。事件は消えず、主人公と澪の依存と破損した信頼が残る。証拠を残す→灯里の現在事件を解く。澪の過去を聞かず島を出る→通常。澪を紗夜の代役にせず、冬木の原記録と紗夜の全文を一緒に読む→TRUE。
最後の手紙は「私を弔いに来て、なんて言ったら、あなたは一生ここから帰れないね。だから生きているうちに言う。一緒に島を出て」の中間切取り。終盤で題名と招待状の意味を回収。許しを強要せず、数か月後の再会と新しい約束まで描く。
