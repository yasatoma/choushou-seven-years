# 弔鐘は七年前を告げる

**[ブラウザで遊ぶ](https://yasatoma.github.io/choushou-seven-years/)**

死んだ恋人の筆跡で、招待状が届いた。
嵐に閉ざされた島の洋館。亡き恋人に似た女性と、内側から閉ざされた礼拝堂。
現在の事件と七年前の秘密を追う、オリジナルのミステリー＋恋愛ノベルです。

## 遊び方

Windowsでは **Start-Game.cmd** をダブルクリックしてください。Node.js 22以降が必要です。このPCでは利用可能です。
または、このフォルダで `npm start` を実行し、[ゲームを開く](http://localhost:4175/) を選びます。プレイのための `npm install` は不要です。
HTMLファイルを直接ダブルクリックするのではなく、上の方法で起動してください。終了時は起動したターミナルで Ctrl+C。

- クリック・タップ・Enter・Space：本文を一括表示、もう一度で次の文章へ。
- 選択肢：時間制限なし。調査順を選べます。推理を間違えても再検討できます。
- L：履歴、S：セーブ、A：オート、Esc：メニュー。
- 本文が長い時や文字を大きくした時は、メッセージ欄をスクロールして読めます。
- 設定：文字速度・サイズ、音楽・環境音・効果音、オート待ち時間、演出低減。

全3エンディング（True Endあり）。全分岐合計 約4.5万字・58場面・1,281段落。
一周はおおむね60〜150分（True Endは90〜150分）を想定。分岐と読む速さによって変わり、文章量からの目安であってプレイヤー実測ではありません。
殺人、火災、喪失、家族による束縛を描きます。流血画像や突然の大音量演出はありません。台詞の音声読み上げはありません。

## 本文のルビ

難読語と登場人物名は、**実際に読む順番で各章の初出だけ**、本文の上に読みを表示します。タイトル、章題、発言者名には付けません。履歴にも表示され、保存や引き継ぎのあとも訪問履歴から再現します。
文字送りでは「弔鐘＋ちょうしょう」を一つの単位として出し、読みだけが先に見えることを防ぎます。

## 保存・引き継ぎ

6枠の手動セーブ、自動セーブ、ロード前のバックアップがあります。既読スキップは未読と選択肢で止まります。到達した章の読み返しと、読了済みの結末の栞も利用できます。
保存先はブラウザのlocalStorage、識別子は `choushou.v1`。旧作の保存とは独立しています。ブラウザの保存データを削除すると記録も消えるので、必要な時は引き継ぎを書き出してください。

「引き継ぎ」からコードを発行して、別の端末の本作へ貼り付けるか、テキストファイル・QR画像で移せます。現在位置・選択・証拠・履歴・既読・読了を引き継ぎ、受取側の既読・読了と統合します。手動保存枠・設定・章の栞は端末ごとです。QR画像の読取は端末内で処理します。
他作品のコードは受け付けません。保存はURLの接続先ごとに分かれるため、localhostと別ホストの間も引き継ぎ機能で移してください。

## 配布・開発

`npm run build` で `dist/` に配布用フォルダを作ります。ZIP版は `release/choushou-seven-years-v1.0.0.zip`。解凍後のStart-Game.cmdでも起動できます。
静的ホスティングの場合は、distのindex.html・src・assetsを同じ階層で配置できます。GitHub Actionsで自動テストを通してからGitHub Pagesへ公開します。配信対象はindex.html・src・assetsのみです。公開リポジトリのdocs/spoilersにはネタバレを含む制作資料があります。

```powershell
npm ci
npm test
# npm start を別ターミナルで起動してから
npm run test:browser
node tests/interaction.mjs
npm run build
```

仕様はdocs/SPEC.md、作業記録はdocs/WBS.md、検証結果はdocs/TEST-REPORT.md。
**docs/spoilers内は全シナリオと真相の制作資料です。未プレイ時は開かないでください。** 配布物には含めません。
